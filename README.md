# TopRacerLauncher

Игровой лаунчер для ПК в стиле **Playnite**: тёмная тема, сетка обложек игр,
закрытая система с паролем и таймер игры.

Готовый файл: **`dist\TopRacerLauncher.exe`** — один самодостаточный .exe,
работает на Windows 10/11 без установки чего-либо ещё.

---

## Возможности

| Функция | Как работает |
|---|---|
| **Закрытая система** | При включении ПК и при каждом запуске — вход по паролю. Первый запуск создаёт пароль администратора (минимум 4 символа; хранится как PBKDF2-хэш с солью, а не «сырой» SHA-256). Ввод показывается звёздочками. После 3 неверных попыток — пауза 10 секунд. |
| **Выход только админа** | Закрыть лаунчер (крестик, Alt+F4, кнопка «Выход») можно только с паролем администратора. |
| **Замок (Ctrl+2)** | В шапке — замок: зелёный открытый = окно разблокировано (можно свободно сворачивать). **Ctrl+2** запирает окно (красный закрытый замок): свернуть или открыть настройки можно только после пароля. |
| **Полный экран** | Библиотека открывается развёрнутой без рамки Windows. Свернуть (в том числе Win+D) и закрыть можно только после ввода пароля — иначе окно сразу возвращается. Отключается галочкой «Полный экран» в админ-меню. |
| **Один экземпляр** | Второй запуск не создаёт второй таймер: лаунчер сообщает, что уже запущен. |
| **Список игр** | Сетка обложек (как в Playnite). Клик по обложке — запуск игры. У каждой игры можно менять обложку и задний фон. |
| **Правый клик по игре** | На любой карточке — контекстное меню: **«Играть»**, **«Настроить игру…»** (название/файл/обложка), **«Обложка…»**, **«Задний фон…»**, **«Удалить из библиотеки»**. Настройка, картинки и удаление требуют пароля администратора. |
| **Размер и пропорции карточек** | В верхней панели — **ползунок** «Иконки» (100–380 px). Пропорции — в админ-меню: **3:4**, **1:1**, **16:9**, **2:3**. Значения запоминаются. |
| **Пауза таймера** | Кнопка **⏸ / ▶** рядом с таймером — остановить и продолжить отсчёт без потери времени. |
| **Фон приложения** | Ctrl+1 → «Оформление» → «Фон приложения»: картинка позади библиотеки — файл с компьютера или поиск в интернете, с затемнением для читаемости. |
| **Поиск игр (скан)** | Ctrl+1 → «Найти игры (скан)»: лаунчер сам находит установленные **Steam, Epic, GOG** игры и **ярлыки с рабочего стола** (`.lnk` и `.url`-ссылки Steam/Epic/GOG). Ярлыки с рабочего стола отмечены сразу — проверьте и нажмите «Добавить выбранные (N)». «Пуск» не сканируется, чтобы в библиотеку не попадали калькулятор и панель управления. Есть фильтр по названию. |
| **Обложки из Steam** | При добавлении игр лаунчер сам подтягивает обложку 600×900 и широкий фон по appid из Steam, а для ярлыков — по названию. Кнопка **«Обложки для всех»** дозаполняет картинки у игр, добавленных раньше. Отключается галочкой в админ-меню. |
| **Картинки из интернета** | «Обложка…» / «Задний фон…» → поиск по названию через магазин Steam: портретные обложки 600×900 и широкие фоны. В выдаче остаются только игры — DLC, наборы и саундтреки отсекаются. Либо файл с компьютера. |
| **Напоминания о времени** | За **5 и 1 минуту** до конца сеанса — карточка-напоминание поверх окон (не забирает фокус и не сворачивает игру): «Осталось 5 минут» и кнопка **«+5 минут»**, которая продлевает сеанс после ввода пароля. Таймер краснеет ближе к концу. |
| **История и статистика** | Ctrl+1 → «История»: сколько времени выдано по дням за неделю (столбики), последние события — запуски игр, истечение сеанса, смена пароля, **неудачные попытки ввода пароля**. Журнал лежит в `%APPDATA%\TopRacerLauncher\history.jsonl`. |
| **Звук при неверном пароле** | Каждая неудачная попытка входа и админ-меню сопровождается системным звуком — слышно, если кто-то пытается подобрать пароль. Отключается галочкой в админ-меню. |
| **Таймер игры** | Длительность сеанса фиксируется один раз (по умолчанию 60 минут), вручную в приложении больше не выставляется. Остаток считается по абсолютному дедлайну: перезапуск не добавляет минуты. По истечении игра закрывается вместе с дочерними процессами (Job Object), доступ блокируется. |
| **Режимы таймера** | В админ-меню: **Стоп** (без ограничения), **30 минут**, **1 час** и ползунок 30–240 минут. Состояние («Осталось…» / «Таймер выключен») видно в карточке. |
| **Замок на игру** | Правый клик по игре → «Заблокировать игру»: карточка помечается замком, запуск требует пароля администратора. |
| **Запуск игры** | При старте игры поверх экрана появляется «Игра запускается, ждите…», а окна Steam/Rockstar прячутся. |
| **Кнопки окна** | В правом верхнем углу — стандартные «—», «□», «✕» (свернуть / развернуть / закрыть). Свернуть и закрыть можно только с паролем, если замок закрыт. |
| **Обновления** | В админ-меню → «Система» укажите ссылку на `update.json` (URL или папка). При запуске программа сама проверит версию и предложит «Загрузить и обновить» — скачает новый exe, заменит и перезапустится. |
| **Чат** | Пузыри сообщений, аватар, разделители дат, панель из ~60 игровых эмодзи; история хранится в `%APPDATA%\TopRacerLauncher\chat`. |
| **Таймер можно выключить** | Галочка «Ограничение по времени» в админ-меню: таймер, напоминания и блокировка исчезают — лаунчер превращается в обычную библиотеку с паролем на выход. |
| **Стеклянный дизайн** | Размытый фон на всё окно, полупрозрачные панели с светлой кромкой, скруглённые карточки, отдельная карточка выбранной игры справа с обложкой, годом, разработчиком, жанрами и описанием. |
| **Метаданные из Steam** | Ctrl+1 → «Метаданные»: описание, разработчик, издатель, жанры, год выхода и оценка Metacritic подтягиваются из Steam и сохраняются в библиотеке. «Обложки для всех» заодно добирает метаданные. |
| **Статистика использования** | Ctrl+1 → «Использование»: сколько раз запускали лаунчер, с каких учётных записей Windows и машин, как часто за последнюю неделю. Общий файл `%PROGRAMDATA%\TopRacerLauncher\usage.json`. |
| **Без окон магазинов** | Галочка «Скрывать окна Steam/Rockstar»: при запуске игры окно лаунчера магазина прячется, игра открывается сразу. |
| **Steam/Rockstar под контролем** | При окончании сеанса и всё время блокировки лаунчер закрывает Steam, Rockstar, Epic, GOG, Ubisoft, EA и Battle.net — из них нельзя запустить игру в обход таймера. Отключается галочкой в админ-меню. |
| **Блокировка по таймеру** | Экран «Доступ ограничен»: пока не введён пароль — играть нельзя. Ввод пароля = **новый сеанс** с последней установленной длительностью. |
| **Админ-меню (Ctrl+1)** | Запрос пароля → время, игры (скан/вручную/картинки), пропорции и тема, история, смена пароля, автозагрузка, звук, полный экран. |
| **Темы оформления** | В админ-меню — **13 тем** (7 старых + мятная, голубая, индиго, янтарная, малиновая, графит). Цвета применяются сразу и запоминаются. |
| **Анимации** | Плавное появление окон, увеличение карточки при наведении, мягкие переходы кнопок и ползунков. |
| **Автозагрузка** | Галочка в админ-меню ставит ярлык в «Папку автозагрузки» — лаунчер сам стартует при включении ПК. |
| **Достижения** | Кнопка **«Достижения»** на нижней панели: 20 наград за часы игры, серии дней, число игр и коллекцию. Прогресс считается из уже накопленной статистики (`playtime.jsonl` и журнала событий), поэтому ничего не теряется и старые сессии тоже засчитываются. При открытии награды в углу появляется тост — игру он не сворачивает. |

## Первый запуск

1. Запустите `TopRacerLauncher.exe`.
2. **Придумайте пароль администратора** (минимум 4 символа) — он же пароль входа.
   Запишите его: без пароля доступ к лаунчеру закрыт.
3. Сразу выдаётся первый сеанс — 60 минут (меняется в админ-меню).

## Как добавить игру

1. Нажмите **Ctrl+1** → введите пароль.
2. Способ А — **автопоиск**: кнопка **«Найти игры (скан)»**.
   Лаунчер просканирует Steam / Epic / GOG и ярлыки (Рабочий стол, «Пуск»),
   покажет список — отметьте галочками **несколько игр сразу** и нажмите
   «Добавить выбранные (N)». Поле сверху фильтрует список по названию.
   Обложки и фоны для добавленных игр подтянутся из Steam автоматически.
3. Способ Б — **вручную**: «Добавить вручную» → название + `.exe`/`.lnk` игры.
4. **Картинки**: выделите игру в списке →
   - **«Обложка…»** — поиск в интернете по названию (Steam) или файл с компьютера;
   - **«Задний фон…»** — широкая картинка позади обложки в карточке;
   - **«Обложки для всех»** — дозаполнить картинки сразу у всех игр без обложек.

   Скачанные картинки хранятся в `%APPDATA%\TopRacerLauncher\media\`.

5. **Правый клик по карточке игры** в библиотеке — быстрое меню:
   «Играть», «Настроить игру…», «Обложка…», «Задний фон…», «Удалить из библиотеки».
   (Настройка/картинки/удаление спросят пароль администратора.)
   В админ-меню двойной клик по игре в списке — тоже открывает настройку игры.

## Как выдать время (таймер)

1. **Ctrl+1** → пароль.
2. Раздел **Время игры**:
   - нажмите готовую плашку **30 минут** или **60 минут**,
   - либо выберите ползунком/введите от 30 до 240 минут;
3. **Установить и запустить таймер** — отсчёт пошёл, виден вверху справа и внизу.
4. **Пауза**: кнопка **⏸** рядом с таймером останавливает отсчёт,
   **▶** — продолжает. Полезно, если нужно отлучиться.

Когда время истекло:
- запущенная игра **закрывается принудительно** (вместе с дочерними процессами);
- появляется экран **«Доступ ограничен»**;
- ввод пароля → **новый сеанс** с последней установленной длительностью.

За **5 и 1 минуту** до конца появляется напоминание поверх окон с кнопкой
**«+5 минут»**: продление требует пароля администратора.

Кнопка **Сбросить время** — немедленно закрыть игру и заблокировать доступ.

## Достижения

20 наград, каталог зашит в код (`Achievements.cs`). Считать ничего вручную не нужно:
прогресс выводится из того, что лаунчер и так записывает — время по играм и журнал
событий. Поэтому после обновления достижения появляются «задним числом», за все
прошлые сессии.

- **Часы:** 1, 10, 50, 100, 500.
- **Игры:** 5, 10, 25 разных игр; 10 и 25 игр в библиотеке.
- **Запуски:** первый запуск, 10 и 100 запусков.
- **Серии:** 3, 7 и 30 дней подряд.
- **Особые:** марафон на 2 часа без перерыва, запуск до 8 утра, три разные игры
  за день, неделя без попыток подобрать пароль.

Открытые награды показываются первыми, дальше — ближайшие к цели. Прогресс
проверяется при завершении игры, при старте лаунчера и при открытии окна, так что
«забытых» наград не остаётся. Список лежит в
`%APPDATA%\TopRacerLauncher\achievements.json` — это обычный JSON, его можно
перенести на другой ПК вместе с `playtime.jsonl`.

Достижения — про мотивацию, а не про защиту: файлы лежат в профиле пользователя,
и он может их отредактировать, как и `config.json`.

## Где хранятся настройки

`%APPDATA%\TopRacerLauncher\config.json` — пароль (хэш), время, список игр.
Рядом лежит `config.json.bak` (предыдущая удачная версия) и, если файл когда-то
был повреждён, `config.json.corrupt-…` — испорченная копия не удаляется.

Запись атомарная (через `.tmp` + переименование), поэтому выключение ПК в момент
сохранения не превращает конфиг в обрезанный JSON.

Журнал событий — `%APPDATA%\TopRacerLauncher\history.jsonl` (одна JSON-строка на
событие, старые записи ротируются в `history.jsonl.old`). Картинки — в `media\`.
Достижения — в `achievements.json`, время по играм — в `playtime.jsonl`.

## Безопасность: что это даёт, а что нет

Что сделано:

- пароль хранится как **PBKDF2-SHA256** (210 000 итераций, случайная соль),
  а не как одиночный SHA-256 — офлайн-перебор по украденному `config.json` стал
  в тысячи раз медленнее; старые хэши автоматически обновляются при первом входе;
- минимальная длина пароля — 4 символа;
- отладочные режимы (`--demo-admin`, `--demo-main`), которые открывали админ-меню
  без пароля, остались **только в Debug-сборке** и в релизный exe не попадают;
- битый конфиг больше не «молча обнуляется»: лаунчер пробует `config.json.bak`,
  а если не вышло — показывает ошибку и **не перезаписывает** файл;
- оставшееся время считается по абсолютному дедлайну, а запущенная игра
  привязана к Job Object — её нельзя «потерять», закрыв лаунчер;
- каждая неудачная попытка ввода пароля **озвучивается** и попадает в журнал
  вместе с временем и номером попытки — видно, если кто-то подбирает пароль
  или трогает настройки ночью.

Чего это **не** даёт:

- Это ограничение, а не защита от администратора компьютера. `config.json` лежит
  в профиле пользователя, и этот же пользователь может его удалить или
  отредактировать (удаление = первый запуск = свой пароль), а также снять процесс
  лаунчера через диспетчер задач.
- Если нужна настоящая защита, её строят иначе: отдельная учётная запись Windows
  для ребёнка, лаунчер из-под администратора/службы, `config` в `%PROGRAMDATA%`
  с ACL (запись только админу), запуск через планировщик задач и запрет
  диспетчера задач групповой политикой.

## Сборка из исходников

Нужен .NET 8 SDK (устанавливается без прав администратора):

```powershell
Invoke-WebRequest https://dot.net/v1/dotnet-install.ps1 -OutFile dotnet-install.ps1
.\dotnet-install.ps1 -Channel 8.0 -InstallDir $env:LOCALAPPDATA\dotnet8
```

Затем:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

`build.ps1` сам находит SDK (в `%LOCALAPPDATA%\dotnet8`, в `%ProgramFiles%\dotnet`,
в PATH), собирает `dist\TopRacerLauncher.exe` и прогоняет самопроверку.

Ручная команда сборки:

```powershell
dotnet publish src\TopRacerLauncher -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist
```

### Самопроверка приложения

```powershell
.\dist\TopRacerLauncher.exe --smoke-test
# код выхода 0 и файл %TEMP%\TopRacerLauncherSmoke\smoke-ok.txt = проверка пройдена
```

Самопроверка не только создаёт все окна, но и проверяет логику: PBKDF2 и миграцию
старого хэша, сохранение/загрузку конфига, восстановление из `.bak`, отказ
перезаписывать битый конфиг, безопасное удаление картинок, расчёт остатка времени
и выбор главного `.exe` игры. При ошибке пишется `smoke-fail.txt` с причинами.

## Структура проекта

```
TopRacerLauncher/
├── build.ps1                  — сборка + самопроверка
├── dist/TopRacerLauncher.exe  — готовый лаунчер
├── tools/gen_icon.ps1         — генерация иконки
└── src/TopRacerLauncher/
    ├── App.xaml(.cs)           — точка входа, пароль, сеанс, экран ограничения
    ├── MainWindow.xaml(.cs)    — библиотека игр, таймер, Ctrl+1, выход по паролю
    ├── AdminWindow.xaml(.cs)   — админ-меню: время, игры, картинки, пароль, автозагрузка
    ├── ScanWindow.xaml(.cs)    — поиск установленных игр (скан) с множественным выбором
    ├── CoverSearchWindow.xaml(.cs) — поиск обложек/фонов в интернете
    ├── ImageSearchService.cs   — API поиска и скачивания картинок (Steam)
    ├── ImageCache.cs           — кэш декодированных обложек (без повторного чтения диска)
    ├── GameScanner.cs          — сканер Steam / Epic / GOG / ярлыков
    ├── LoginWindow.xaml(.cs)   — вход / ограничение / запрос пароля
    ├── MaskedInput.cs          — поле пароля со звёздочками
    ├── FirstRunWindow.xaml(.cs)— создание и смена пароля
    ├── ToastWindow.xaml(.cs)   — напоминание «осталось N минут» с продлением
    ├── AddGameWindow.xaml(.cs) — добавление игры вручную
    ├── GameRunner.cs           — запуск и прикрытие окон лаунчеров (Job Object)
    ├── SteamMetadataService.cs — описание, жанры, разработчик из Steam
    ├── UsageStats.cs           — статистика запусков и учётных записей
    ├── ConfigStore.cs          — конфиг и хэширование пароля (PBKDF2 + соль)
    ├── HistoryLog.cs           — журнал событий и статистика по дням
    ├── Achievements.cs          — каталог из 20 достижений и подсчёт прогресса
    ├── AchievementsWindow.xaml(.cs) — полка достижений
    ├── AchievementToast.xaml(.cs)   — тост «Достижение открыто»
    ├── SoundAlert.cs           — системные звуки (неверный пароль, напоминания)
    ├── SelfTest.cs             — логические проверки для --smoke-test
    ├── Theme.xaml              — тёмная тема в стиле Playnite
    └── Models.cs               — модели настроек и карточек
```
