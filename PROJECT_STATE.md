﻿# TopRacerLauncher — состояние проекта

Документ для продолжения работы в новой сессии. Здесь всё, что сделано, как собрать, где лежит и что осталось.

---

## 1. Что это

Клубный игровой лаунчер для **Top Racer VR Club Z7** (Windows, WPF, .NET 8, single-file self-contained exe).
Клиент садится за ПК → лаунчер на весь экран → выбирает игру → играет оплаченное время.
Администратор управляет всем через админ-меню (по паролю).

**Репозиторий (публичный):** https://github.com/qpokyc07/TopRacerLauncher
**Релизы (автообновления):** https://github.com/qpokyc07/TopRacerLauncher/releases
**Текущая версия:** см. `src/TopRacerLauncher/TopRacerLauncher.csproj` (`<Version>`)

## 2. Как запускать и собирать

- **Рабочая копия:** `C:\TopRacerLauncher\TopRacerLauncher.exe` + ярлык `TRLauncher` на рабочем столе.
  ⚠️ Из папки проекта exe не запускается (ACL-ограничение DSH), поэтому `build.ps1` копирует его в `C:\TopRacerLauncher`.
- **Сборка:** `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1`
  (находит SDK в `%LOCALAPPDATA%\dotnet8\dotnet.exe`, публикует single-file, копирует в `C:\TopRacerLauncher`).
- **Смоук-тест:** `dotnet <dll> --smoke-test` → маркер `%TEMP%\TopRacerLauncherSmoke\smoke-ok.txt`
  (15 проверок: пароль PBKDF2, конфиг, .bak, медиа, таймер, журнал, промокоды, окна и т.д.).
- **Git:** портативный в `%LOCALAPPDATA%\PortableGit\bin\git.exe`, GitHub CLI — `%LOCALAPPDATA%\gh\bin\gh.exe`.
  Для команд: `$env:Path = "$env:LOCALAPPDATA\PortableGit\bin;$env:LOCALAPPDATA\gh\bin;$env:Path"`.
- **Выпуск релиза:**
  1. поднять `<Version>` в csproj;
  2. `build.ps1`;
  3. обновить `update.json` (version + url на vX.Y.Z);
  4. `git add -A; git commit -m "..."; git push`;
  5. `gh release create vX.Y.Z "dist\TopRacerLauncher.exe" "update.json" --title "..." --notes "..."`.

## 3. Данные пользователя

- Настройки: `%APPDATA%\TopRacerLauncher\config.json` (+ `.bak`, `.corrupt-*`)
- История событий: `history.jsonl`
- Статистика времени: `playtime.jsonl`
- История чатов: `chat\<peerId>.jsonl`
- Картинки: `media\`
- QR-коды клуба: `%APPDATA%\TopRacerLauncher\qr\qr1..3.png` (перекрывают встроенные)
- Крэш-лог: `crash.log`

Пароль хранится как PBKDF2-SHA256 (210 000 итераций, соль), версия хэша в конфиге.

## 4. Что уже реализовано

### Библиотека игр
- Карточки с обложками (Steam CDN), автоматическая загрузка метаданных на русском (описание, жанры, год, разработчик, Metacritic).
- Скан: Steam/Epic/GOG + **ярлыки с рабочего стола** (.lnk/.url). «Пуск» не сканируется (мусор).
- Добавление вручную, обложки/фон вручную, «Метаданные всем».
- Скрытие игр вне админ-режима (правый клик → «Скрыть игру»).
- Пропорции карточек (3:4, 1:1, 16:9, 2:3), ширина карточек (сейчас уже — 162), названия цветом темы (опция).
- Живые карточки: зум, тень, градиент снизу; skeleton-шиммер пока нет обложки.

### Время и сессии
- Таймер по дедлайну (не счётчик), пауза убрана с главного экрана.
- Админ-меню → «Таймер»: **Стоп / 30 минут / 1 час + ползунок 30–240**.
- Тарифы на экране приветствия: **30 мин / 1 час / 2 часа** (по паролю) — запускают сессию.
- Предупреждения «осталось 5/1 мин», блокировка по истечении, «+5 минут» по паролю.
- «Завершить сессию» (кнопка админа) — закрывает игру, сбрасывает таймер, показывает приветствие.
- Диалог «Время игры» убран из админки (заменён тарифами/таймером).

### Чат и звонки (локальная сеть)
- Автообнаружение друзей по UDP-broadcast (порт 47771), статусы: в сети / играет / в звонке / отошёл / не беспокоить.
- «Печатает…» в списке друзей и на вкладке чата.
- Чат: одно окно, вкладки для каждого собеседника, пузыри, история в файлах, стикеры-наклейки (12 шт., эмодзи убраны), масштабирование окна (размер сохраняется).
- Непрочитанные: красный бейдж + красное всплывающее уведомление, звук.
- Голосовой чат: комната до 4 человек, приглашение с выбором друзей, PTT (своя клавиша) или постоянная передача, выбор микрофона/наушников, индивидуальная громкость по ПКМ, громкость своего микрофона, звук вызова.

### Клуб / киоск
- Экран приветствия: «Добро пожаловать» → Top Racer, 3 QR (Telegram/VK/MAX), тарифы, «Начать», ссылка @qpokycnow.
- Киоск-режим (галочка в админке): скрывает панель задач, блокирует Win/Alt+Tab/Alt+F4/Ctrl+Esc, окно поверх всех.
- «Игра запускается, ждите…» — по центру экрана, + скрытие окон Steam/Rockstar.
- Логотип клуба в шапке (прозрачный фон), акцентные кнопки Браузер/Steam.

### Промокоды и акции
- Админ-меню → «Промокоды»: создать код (минуты, число использований, срок), список, удаление.
- На главном — кнопка «Промокод» → окно ввода → минуты добавляются (или стартует сессия).
- Кнопка «Хочешь до 30 минут бесплатно?» → окно с QR соцсетей и текстом про +10 минут.

### Статистика
- `playtime.jsonl`: время по играм, запуски, «сегодня / 7 дней / всё время» (админ-меню).
- Журнал событий: запуски, завершения, попытки пароля, промокоды.
- Использование ПК: запуски по пользователю/машине.

### Обновления
- `update.json` (version/url/notes) в GitHub Releases; проверка при старте.
- Установка **без cmd-скрипта**: новый exe копируется рядом, запущенный переименовывается в `.old`, новый встаёт на место и запускается; хвосты удаляются при старте.
- Админ-меню → «Обновления»: ссылка на манифест + «Сохранить и проверить».

### Оформление
- 27 тем, включая **градиентные** (трёхцветные): Закат, Океан, Неон, Кибер, Сияние, Золото.
- Темы — прокручиваемая полоса цветных образцов; сохраняется в конфиге.
- Полупрозрачные панели (опция), тёмные контекстные меню, тонкий скроллбар (3 px, подсветка при наведении).
- Стеклянный перелив на кнопках при наведении, плавное появление окон.

### Достижения (добавлено в 1.9.0)
- 20 наград за часы, серии дней и коллекцию игр; прогресс считается из уже накопленной статистики.
- Кнопка «Достижения» на нижней панели открывает полку; при открытии награды показывается тост.

### Окно входа
- Компактное прямоугольное окно (540×268): иконка слева, поле и кнопки справа.
- Крестик закрытия доступен всегда (даже до ввода пароля).

### Характеристики ПК
- В правой панели под описанием игры — блок «Характеристики ПК» (процессор, память, видео, ОС, разрешение), сворачивается кликом.

### Запуск Steam-игр
- steam://rungameid/<id> преобразуется в запуск steam.exe -applaunch <id> (надёжнее, чем URL-ассоциация; помогает при ошибках сертификатов).

### Горячие клавиши
- `Ctrl+1` — админ-меню (также клик по логотипу).
- `Ctrl+2` — переключить замок (админ-режим).
- `Ctrl+K` — командная палитра (игры + действия).
- `V` (настраивается) — Push-to-Talk в звонке.
- `Esc` — закрыть справку/промо/палитру.

## 5. Известные проблемы и что проверить

1. **CS2 не запускается через лаунчер** — пользователь видит сообщение о сертификатах.
   Запуск идёт через `steam://rungameid/730`. Нужно проверить:
   - лаунчер запущен НЕ от администратора (Steam/VAC не любят elevated);
   - попробовать запуск через `steam.exe -applaunch 730` вместо URL (запланировано);
   - точный текст ошибки (скриншот) — от этого зависит решение.
2. **Второй ПК**: старые версии (до 1.8.1) не умели устанавливать обновления — один раз заменить exe вручную, дальше обновится само.
3. `Ctrl+K` в автоматических тестах не открывался (проблема фокуса теста); у пользователя работал.

## 8. Важные технические детали

- **Единственный экземпляр:** `Mutex("Local\TopRacerLauncher.SingleInstance")`; `ShutdownMode = OnExplicitShutdown`.
- **Таймер:** `SessionEndUtc` (дедлайн), пауза — `TimerPaused` + `PausedRemainingSeconds`.
- **Закрытая система:** свернуть/закрыть можно только при `App.AdminUnlocked` (зелёный замок) или по паролю.
- **Публикация:** single-file self-contained, `IncludeNativeLibrariesForSelfExtract`, NuGet `NAudio 2.2.1`.
- **Пути с кириллицей:** cmd-скрипты для обновления больше не используются (была причина сбоев).
- **Цвета/фон:** `Themes.Apply` подменяет кисти в `Application.Resources` (`AccentBrush`, `BgWindowBrush` и т.д.).
